# Jeninnet.Localization

Jeninnet.Localization is a modular localization framework for .NET applications: key-driven message lookup, resource-set storage, file and database providers, ASP.NET Core integration, and optional translation providers.

This site is the searchable edition of the repository's documentation. It is generated from the Markdown in the repository; `docs/` remains the source of truth for the book.
