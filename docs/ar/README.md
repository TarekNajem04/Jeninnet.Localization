أسئلة تساعدك أثناء القراءة:

1. هل يبدو النص مكتوباً بالعربية من البداية، أم ما زالت فيه بنية جملة إنجليزية؟
2. هل المصطلحات طبيعية لمهندس عربي، أم تحتاج لفظاً أدق؟
3. هل أي فقرة تكرر فكرة سابقة أو لا تضيف خطوة إلى الفهم؟
4. هل أمثلة الكود واضحة، وهل اتجاه الكود صحيح عند العرض؟
5. هل توجد جملة تبدو ترجمة حرفية رغم سلامتها النحوية؟

## ما لا يُترجم

أسماء الحزم والمساحات البرمجية والأنواع والأعضاء وأوامر CLI وأسماء الإعدادات تبقى كما هي. أمثلة
الكود تبقى كما هي أيضاً، حتى تظل قابلة للمقارنة مع المشروع وللتحقق الآلي.

مراجعاً يتحدث العربية، وتحديثاً عند تغير الفصل الإنجليزي.
