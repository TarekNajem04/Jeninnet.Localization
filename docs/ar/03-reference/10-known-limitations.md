# القيود المعروفة وحدود الدعم (known limitations and support boundaries)

هذه الصفحة ورقة الحدود الصادقة للمكتبة. إنها ليست قائمة أخطاء: كل بند خيار تصميم متعمَّد، أو حد
نطاق حالي، أو مسؤولية تخص المضيف أو المستهلك. اقرأها قبل اعتماد المكتبة، واتبع الفصل المشار إليه
للسلوك الكامل.

النسخة القصيرة: تملك المكتبة حل الرسائل والتنسيق واختيار المزوّد وعقود المخزن والأدوات المحيطة
بالكتالوجات. ولا تملك التخطيط ولا إدارة الترجمة ولا توفير قواعد البيانات ولا تفويض التطبيق.

## البنية وخط الأنابيب

- **مزوّد رسائل واحد بالضبط لكل تركيب.** صفر مزوّدين صالح ويجعل عمليات البحث تعيد
  <code dir="ltr">null</code>؛ وأكثر من واحد يرمي عند إنشاء محدد المزوّد. ولا يوجد تسلسل ولا ترتيب
  أولوية ولا تجميع ولا ارتداد على مستوى المزوّد. راجع
  [النموذج الذهني](../01-getting-started/04-mental-model.md).
- **المزوّدات مطابقة تماماً.** يحل المزوّد مفتاحاً واحداً لثقافة واحدة. ولا يمشي في ثقافات الآباء
  أبداً ولا يطبّق الثقافة الافتراضية. وذلك المشي ملك
  <code dir="ltr">DefaultMessageLocalizer</code> وحده. راجع
  [الثقافات والارتداد](../02-guides/03-cultures-and-fallback.md).
- **الارتداد ثابت.** الثقافة المطلوبة، ثم ثقافات آبائها، ثم الثقافة الافتراضية المكوَّنة. ولا
  تُستعلم الثقافة الثابتة أبداً. وتُلتقط الثقافة الافتراضية عند إنشاء المُعرِّب؛ وتعديل الخيارات
  لاحقاً بلا أثر. راجع [واجهة Core API](01-core-api.md).
- **الغياب ليس خطأ.** الغياب الكامل يعيد <code dir="ltr">null</code>؛ ولا يُنادى المنسّق. وتنتشر
  استثناءات المزوّد والمنسّق، بما فيها الإلغاء. ولا يُحوَّل الإلغاء إلى غياب أبداً. راجع
  [واجهة Core API](01-core-api.md).
- **لا يوجد محرك تعريب ثانٍ.** مزوّدو الترجمة ومزوّدو الملفات وقواعد البيانات كلهم مزوّدون
  عاديون. وتسجيل أحدهم لا يضيف طبقة ارتداد خلف آخر.

## الثقافة وواجهات المستهلك

- **<code dir="ltr">IStringLocalizer</code> جسر، لا مالك الارتداد.** يلتقط الجسر
  <code dir="ltr">CurrentUICulture</code> عند إنشاء المُعرِّب، ويفحص مجموعة موارد دقيقة واحدة في
  كل بحث، ولا يمشي في ثقافات الآباء. والقيمة المفقودة
  <code dir="ltr">[MISSING:key]</code> مع <code dir="ltr">ResourceNotFound = true</code>. راجع
  [واجهة Core API](01-core-api.md).
- **لا تسجيل لـ <code dir="ltr">IStringLocalizer</code> جذري.** الجسر مقصود لـ
  <code dir="ltr">IStringLocalizer&lt;T&gt;</code> ومسارات المصنع العامة/المحددة النوع في الإطار؛
  راجع مرجع Core قبل افتراض وجود مُعرِّب جذري.
- **المخزن المسجّل لا يغذّي <code dir="ltr">IMessageLocalizer</code>.** يقرأ خط أنابيب الرسائل
  <code dir="ltr">IInnerMessageProvider</code>؛ ويغذّي المخزن
  <code dir="ltr">IStringLocalizer</code> عبر الجسر. وهذان مساران منفصلان. راجع
  [مجموعات الموارد والمخزن](../02-guides/06-resource-sets-and-store.md).
- **اختيار الثقافة والاتجاه كود مضيف.** تعريب الطلب و<code dir="ltr">CurrentUICulture</code>
  وملفات الارتباط واتجاه التخطيط مسؤوليات تطبيق. وتوفّر المكتبة السلاسل والارتداد، لا وسيط طلب
  ولا سلوك تخطيط خارج التكاملات التي تملكه صراحةً. راجع
  [RTL (Right-to-Left) والنص ثنائي الاتجاه](../02-guides/16-rtl-and-bidi.md).

## المزوّدون ومصادر المحتوى

- **الذاكرة لا تخص الثقافة.** تخدم خريطة مسطحة واحدة وتتجاهل وسيطة الثقافة. استخدم مزوّد
  ملفات/قاعدة بيانات لكل ثقافة أو تركيباً واعياً بالثقافة عندما تختلف الثقافات. راجع
  [مزوّد الذاكرة](https://github.com/TarekNajem04/Jeninnet.Localization/blob/main/src/providers/Jeninnet.Localization.Providers.Memory/README.md).
- **مزوّدات الملفات تُحمَّل عند التسجيل.** تتحقق JSON وXML وPO من محتواها وتقرأه أثناء التسجيل؛
  والملف المفقود أو المشوّه يفشل هناك. وإعادة التحميل الساخنة اختيارية
  (<code dir="ltr">WatchForChanges = true</code>)، ومؤخّرة (debounced)، وعلى الجدول كله لا لكل ثقافة.
- **الموارد المترجمة لا تراقب الملفات.** تقرأ مزوّدات ResX وsatellite موارد مترجمة؛ واستبدال
  <code dir="ltr">.resx</code> أو تجميعة satellite وقت التشغيل يتطلب نشراً جديداً، لا مراقبة
  ملفات.
- **تغييرات قاعدة البيانات تظهر في البحث التالي، لكن لا توجد ذاكرة مزوّد.** كل خطوة ارتداد تفتح
  اتصالاً وتنفّذ استعلاماً قياسياً واحداً. وإذا كانت تلك الكلفة مهمة، فخزّن مؤقتاً فوق المزوّد
  باستراتيجية إبطال متعمدة. راجع [الأداء](../04-operations/03-performance.md).
- **حساسية الحالة تتبع ترتيب قاعدة البيانات.** تقارن مزوّدات قواعد البيانات
  <code dir="ltr">MessageKey</code>/<code dir="ltr">Culture</code> بترتيب العمود. استخدم ترتيباً
  حساساً للحالة (<code dir="ltr">bin</code>) عندما يجب أن تطابق المفاتيح ترتيبياً. راجع README
  المزوّد لمورّدك.

## التنسيق والترميز

- **المنسّق الافتراضي صغير عمداً.** يستبدل العناصر النائبة المسمّاة
  <code dir="ltr">{...}</code>؛ والوسائط المفقودة تبقى حرفية، و<code dir="ltr">null</code> يصبح
  فارغاً، ولا توجد معالجة لسلسلة تنسيق. استخدم منسّق ICU (International Components for Unicode) الاختياري لأنماط
  الجمع/الاختيار/العدد/التاريخ. راجع
  [التنسيق وصيغ الجمع](../02-guides/04-formatting-and-plurals.md).
- **Markdown مجموعة فرعية موثّقة، لا محرك CommonMark كامل.** يعرض منسّق Markdown تلك المجموعة
  ولا يحلّل الوسائط كـ Markdown أو HTML أبداً. وHTML الخام خامل ما لم يُسمح به صراحةً. راجع
  [التنسيق وصيغ الجمع](../02-guides/04-formatting-and-plurals.md).
- **المنسّق الآمن لـ HTML ليس معقّماً.** يرمّز وسائط السلاسل؛ ولا ينظّف ترميز قالب غير موثوق.
  القوالب محتوى موثوق، ويبقى المضيف مسؤولاً عن ترميز المخرجات ومراجعة المحتوى. راجع
  [الأمان](../04-operations/02-security.md).
- **لا ترجمة تلقائية للشظايا.** ترجمة الشظايا المدمجة تنتج ترتيب كلمات خاطئاً وقواعد مكسورة.
  ترجم جملاً كاملة وحافظ على العناصر النائبة. راجع
  [سير عمل المترجمين](../02-guides/11-translator-workflow.md).

## المخزن والإدارة والتاريخ

- **المخزن عقد منفصل.** لا تستبدل <code dir="ltr">ILocalizationStore</code> ونموذج مجموعات
  الموارد مزوّد الرسائل. وتسجيل المخزن وحده لا يجعل <code dir="ltr">IMessageLocalizer</code>
  يخدم الرسائل. راجع [واجهة التخزين](02-storage-api.md).
- **مخزن EF Core يستهدف SQL Server.** تنفيذ المخزن المشحون خاص بـ SQL Server. وهو ليس المخطط نفسه
  لجدول <code dir="ltr">LocalizationMessages</code> في ADO.NET، ولا يهاجر أحدهما الآخر.
- **لا تُشحن ترحيلات EF Core مع الحزمة.** يمكن إنشاء قاعدة بيانات جديدة بـ
  <code dir="ltr">EnsureCreated</code>، لكن فقط عندما تكون قاعدة البيانات فارغة؛ وإدارة المخطط
  مسؤولية المستهلك. راجع [مخطط مخزن EF Core](../04-operations/06-ef-core-store-schema.md)
  للجداول وفحوص التوفير وقواعد التعايش.
- **التعديلات المحكومة تتطلب تفويضاً وتعاوناً.** يسلسل المخزن التعديلات لكل نسخة؛ ولا ينسّق ذلك
  البوابة داخل العملية كتاباً خارج العملية. أضف قيود قاعدة بيانات أو سلسل الكتابات خارجياً. وتتطلب
  الإدارة أيضاً أن يفوض المضيف المستدعين؛ ولا توفّر المكتبة سياسة تفويض.
- **التاريخ دليل تدقيق، لا نسخة احتياطية.** تكشف سجلات التدقيق/التاريخ وسلسلة التجزئة العبث
  وتعيد إنتاج الإصدارات؛ ولا تستبدل نسخ قاعدة البيانات الاحتياطية أو التحكم في الوصول. راجع
  [التدقيق والتاريخ](../02-guides/07-audit-and-history.md).
- **المزامنة بلا حذف.** تضيف <code dir="ltr">ResourceSynchronizer</code> افتراضياً، ولا تحدّث إلا
  عند السماح الصريح، ولا تحذف مفاتيح أو ثقافات أبداً. راجع
  [مجموعات الموارد والمخزن](../02-guides/06-resource-sets-and-store.md).

## مزوّدات قواعد البيانات والمخطط

- **للقراءة فقط بحكم التصميم.** لا تصدر مزوّدات ADO.NET إلا
  <code dir="ltr">SELECT</code>؛ ولا تنشئ جداول ولا تهاجر مخططات ولا تبذر صفوفاً ولا تعيد تحميل
  كتالوجات.
- **لا إنشاء تلقائي للمخطط.** أنشئ جدول <code dir="ltr">LocalizationMessages</code> المرجعي
  بالسكربت الخاص بالمورّد الموصوف في [دليل قاعدة البيانات](../../database/README.md) وابذره
  منفصلاً. ويغطي الدليل أيضاً ترحيل إعادة التسمية السابق للمعيار.
- **لا ذاكرة مزوّد.** اتصال واحد واستعلام واحد لكل خطوة ارتداد. استخدم تجميع الاتصالات والتخزين
  المؤقت على مستوى التطبيق حيث يلزم؛ فمزخرفات ذاكرة المخزن لا تلف مزوّدات الرسائل.
- **توافر قاعدة البيانات هو توافرك.** تنتشر استثناءات المزوّد. وانقطاع قاعدة البيانات لا يُحوَّل
  إلى غياب أو ارتداد، لذا على المضيف أن يقرر كيفية التدهور.

## مزوّدات الترجمة

- **الشبكة وبيانات الاعتماد مطلوبة.** تنادي Azure Translator وGoogle Cloud Translation خدمات حية
  وتتطلبان مفتاح API. ويستخدم المستودع مزوّدات محلية افتراضياً ولا يلتزم بيانات اعتماد أبداً.
- **العناصر النائبة غير مضمونة البقاء في الترجمة الآلية.** ترسل المزوّدات مفتاح الرسالة كقالب
  مصدر وتتلقى نصاً مترجماً؛ حافظ على العناصر النائبة وتحقق منها كجزء من سير عمل الترجمة. راجع
  [الترجمة الآلية](../02-guides/12-machine-translation.md).
- **Google لا يبلّغ عن قدرات متقدمة.** يكشف Azure التخزين المؤقت والتجميع والمسرد والذاكرة
  وضوابط المرونة؛ ومزوّد Google أدنى عمداً. راجع
  [مرجع المزوّدين](03-provider-reference.md).
- **مزوّد الترجمة هو المزوّد الوحيد.** لا يوجد كتالوج ملفات أو قاعدة بيانات خلفه يمتص فشل
  الخدمة. اختر التخزين المؤقت والتدهور عمداً.
- **الترجمة الحقيقية من طرف إلى طرف مقيدة ببيانات الاعتماد.** تستخدم الاختبارات بدائل وسلوكاً
  حتمياً؛ وفقط تشغيل حي بمفاتيح حقيقية يثبت مسار الخدمة الخارجية.

## الأدوات وسلوك وقت البناء

- **المحلل يغطي أشكالاً منسّقة.** يوسم <code dir="ltr">JLNLOC001</code> نص واجهة المستخدم
  والاستثناءات ورسائل التحقق وبيانات العرض و<code dir="ltr">MessageBox</code> وسمات
  <code dir="ltr">Display</code> ومواضع مشابهة. وهو ليس كاشفاً عاماً للسلاسل المضمّنة. راجع
  [مرجع الأدوات](05-tooling-reference.md).
- **إصلاح الكود لا يرجع إلا إلى ثوابت موجودة.** يستبدل النص الحرفي عندما يوجد ثابت
  <code dir="ltr">const string</code> مطابق في نوع ينتهي اسمه بـ <code dir="ltr">Keys</code>؛ ولا
  يستخرج نصاً ولا ينشئ كتالوجات ولا يقدّم إصلاح الكل. راجع
  [README إصلاح الكود](https://github.com/TarekNajem04/Jeninnet.Localization/blob/main/src/analyzers/Jeninnet.Localization.Analyzers.Localizability.CodeFixes/README.md).
- **أداة التكافؤ للتقارير فقط.** تبلّغ عن المفاتيح المفقودة/غير المستخدمة وانحراف القوالب وفجوات
  الصيغ وانحراف العناصر النائبة؛ ولا تكتب الكتالوجات. وتطبيق التغييرات خطوة محكومة صريحة. راجع
  [التكافؤ وبوابات الجودة](../02-guides/13-parity-and-quality-gates.md).
- **مولّد المفاتيح يتطلب مدخلات <code dir="ltr">*.loc.json</code>.** يصدر ثوابت وقت الترجمة؛ ولا
  يكتشف كتالوجات وقت التشغيل ولا يعدّلها. راجع
  [المفاتيح المكتوبة بقوة](../02-guides/05-strongly-typed-keys.md).
- **حزم الأدوات أصول وقت بناء.** المحلل وإصلاح الكود والمولّد وأداة التكافؤ ليست خدمات تعريب وقت
  تشغيل. لا تشير إليها كمكتبات تطبيق.

## AOT والتقليص

- **مخزن EF Core مستبعد من عقد AOT (Ahead-of-Time).** EF Core ليس آمناً بالكامل للتقليص أو AOT؛ استخدم مزوّداً
  غير EF لعمليات نشر trimmed أو Native AOT. راجع [AOT والتقليص](../aot-and-trimming.md).
- **الاكتشاف القائم على الانعكاس موسوم.** تحمل
  <code dir="ltr">LocalizedResourceDiscovery</code> وأسطح التحقق القائمة على الانعكاس وسوم
  <code dir="ltr">RequiresUnreferencedCode</code> / <code dir="ltr">DynamicallyAccessedMembers</code>.
  وعلى عمليات النشر المقلمة توفير تصريحات صريحة أو الحفاظ على الأعضاء الموسومة.
- **اختبار الدخان Native AOT يغطي المسارات المستخدمة.** يثبت التعريب/التنسيق/التخزين
  المؤقت/الترجمة في تركيبه الخاص؛ وهو ليس ضماناً شاملاً لكل مزوّد أو تركيبة مضيف.

## المضيفات والمنصات وواجهة المستخدم

- **.NET 8 و.NET 9 و.NET 10.** تستهدف مكتبات وقت التشغيل <code dir="ltr">net8.0</code> و<code dir="ltr">net9.0</code> و<code dir="ltr">net10.0</code>؛ ولا ادعاء دعم لأطر أقدم. وتستهدف أدوات وقت البناء
  <code dir="ltr">netstandard2.0</code>.
- **مضيفات سطح المكتب تتطلب Windows وقت التشغيل.** تستهدف عينات WinForms وWPF وBlazor Hybrid
  <code dir="ltr">net10.0-windows</code>؛ وتُبنى عبر المنصات لـ CI لكنها تعمل على Windows. ويحتاج
  Blazor Hybrid أيضاً إلى وقت تشغيل WebView2.
- **مضيف Blazor WebAssembly مؤجَّل.** يوفّر تكامل Blazor دلالات WASM (WebAssembly) وحارس المزوّد، لكن لا تُشحن
  عينة مضيف WebAssembly في المتصفح. راجع [Blazor](../02-guides/09-blazor.md).
- **لا واجهة مستخدم ولا CMS ولا نظام إدارة ترجمة.** توفّر المكتبة واجهات وأدوات، لا محرراً ولا
  بوابة مراجعة ولا نقاش مترجمين ولا فوترة ولا إدارة مصطلحات. راجع
  [المقدمة](../01-getting-started/01-introduction.md).
- **لا عينة MAUI أو Avalonia أو Xamarin.** البنية محايدة للمضيف، لكن المضيفات الموثّقة وحدها هي
  المختبَرة.

## العمليات والأداء والأمان

- **لا وعد سعة.** يتضمن المستودع اختبارات أدلة أداء لا تعمل كبوابة، لا مجموعة قياس ولا SLO. ويُهيمن
  زمن المزوّد وعمق الارتداد على الكلفة. راجع [الأداء](../04-operations/03-performance.md) و
  [دليل أداء](../04-operations/07-performance-evidence.md).
- **التخزين المؤقت للمخزن فقط في الصندوق.** يلف
  <code dir="ltr">CachedLocalizationStoreDecorator</code> والمزخرف الموزع المخزن. ولا تقبل مزوّدات
  الرسائل مزخرفاً؛ أضف تخزيناً مؤقتاً على مستوى التطبيق بإبطال صريح. راجع
  [الأداء](../04-operations/03-performance.md).
- **القوالب محتوى موثوق.** لا تعقّم المكتبة ملفات كتالوج أو ترميز قالب غير موثوق. تحقق من ملفات
  التبادل غير الموثوقة وراجع المحتوى المترجم. راجع
  [الأمان](../04-operations/02-security.md).
- **سرية التدقيق تعتمد على التحكم في الوصول إلى قاعدة البيانات.** التنقيح وسلسلة التجزئة آليتا
  سلامة، لا تشفير. احمِ قاعدة البيانات والنسخ الاحتياطية وفقاً لذلك. راجع
  [الأمان](../04-operations/02-security.md).

## الإصدار والتأصيل

- **المشروع غير منشور.** لم تُنشر حزم NuGet؛ والتثبيت يستخدم موجزاً محلياً حالياً. راجع
  [ملاحظات الإصدار](09-release-notes.md).
- **الإصدار عنصر نائب حتى النشر.** <code dir="ltr">1.0.0.0</code> مصرَّح به مركزياً وليس وعد
  توافق منشوراً.
- **لا وتيرة إصدار ولا نافذة LTS موعودة.** تذكر صفحة التوافق الموقف الحالي بصدق؛ لا تستنتج جدولاً
  زمنياً للدعم من رقم الإصدار. راجع
  [التوافق والإصدارات](07-compatibility-and-versions.md).
- **تغييرات واجهة ما قبل الإصدار ممكنة.** تجعلها خطوط أساس الواجهة وسجل التغييرات متعمدة، لكن
  السطح يظل قابلاً للتغيير حتى نشر الحزم.
