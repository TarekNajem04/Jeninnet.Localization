# API Reference Guide

The API reference on this site is generated by DocFX from the XML documentation of the 33 cross-platform packable
projects. It is the class-by-class lookup companion to the narrative reference chapters.

## What is included

- Public and protected types and members only. Internal, private, test, sample, and consumer types
  are not part of the generated reference.
- The 33 cross-platform packable assemblies are represented: core, providers, translation, integrations, interchange,
  generator, analyzer, and tool packages. The Windows-only MAUI and WinUI packages are documented in their package READMEs.
- Pages are grouped by namespace. The package map maps a package to its project and README:
  [Package map](../appendix/02-package-map.md).

The generated YAML under `docs/api/` is not committed; it is rebuilt from the source projects by the
documentation workflow. The narrative reference chapters remain the place for behavior, invariants,
and limits.

## Build-time tooling

The following packages are build-time only. Their API pages document the compiler/tool surface, not a
runtime localization API:

- `Jeninnet.Localization.Generators.Keys` — the source generator. See its
  [README](https://github.com/TarekNajem04/Jeninnet.Localization/blob/main/src/generators/Jeninnet.Localization.Generators.Keys/README.md).
- `Jeninnet.Localization.Analyzers.Localizability` — the `JLNLOC001` analyzer. See its
  [README](https://github.com/TarekNajem04/Jeninnet.Localization/blob/main/src/analyzers/Jeninnet.Localization.Analyzers.Localizability/README.md).
- `Jeninnet.Localization.Tools.Keys` — the `jeninnet-localization-keys` .NET tool. See its
  [README](https://github.com/TarekNajem04/Jeninnet.Localization/blob/main/src/tooling/Jeninnet.Localization.Tools.Keys/README.md).

The analyzer package also carries the non-packable code-fix companion; its API is not a separate
package surface.

## How to navigate it

Use the **API reference** entry in the site navigation. The namespace tree follows the assembly's
public namespaces; the search box covers type and member names across all packages.

Narrative chapters link directly to the member they explain. For example,
<xref:Jeninnet.Localization.Abstractions.IMessageLocalizer> is the localizer contract, and
<xref:Jeninnet.Localization.Abstractions.Store.ILocalizationStore> is the store contract.

## Limits

- Generated pages describe signatures and XML comments, not runtime behavior. Read the linked
  narrative chapter for fallback, caching, failure, and threading rules.
- An assembly with no public API would produce an empty namespace page; the coverage check reports
  missing assemblies, not missing members.
- The generated reference is not versioned separately. It reflects the current source tree, which is
  unreleased; API baselines are the compatibility gate.
